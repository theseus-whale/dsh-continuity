## 1. 这是什么

一个 DSH 插件 + 一套放在 `~/.dsh/continuity` 的本地工具。它做三件事：

1. **存**：把一段对话按线头（thread）收成“段（segment）”，带 `why / next / 残留`；
2. **取**：按标签或 seq 区间把原文取回来（`load`）；
3. **判**：每轮把消息归到某个标签（T），并强制“每条内容都被判过”。

它不接管模型的上下文，也不改 DSH 核心；它只在“折叠前后”和“每轮开头”做事。

## 2. 装了以后目录长什么样

```
~/.dsh/continuity/
  rules.md              习惯全文（第一轮会整篇注入，之后只给标题行）
  tags.json             标签表（T1…Tn）
  threads.json          线头与段（存档索引）
  turn-tags.jsonl       每轮一个标签（轮 → 标签）
  topic-anchors.json    每个标签的“必需词”（不在 tags.json 里，因为会被归一化吃掉）
  generic-words.json    泛词表（区分度低，不能单独当证据）
  t0-decisions.jsonl    显式判 T0 的记录

  turnmap.mjs           turn ↔ seq ↔ 标签 的桥
  t0decide.mjs          判 T0 / 判标签
  newtopics.mjs         save 前的新事物体检
  tag-gap.mjs           标签缺口清单
  match-tags.mjs        查表：这句话像哪个 T
  kw-audit.mjs          词表体检 / explain（泛词不算证据）
  doctor.mjs            修 session 日志格式错（如 system head 损坏）
```

**没有这些工具，闸会拒绝但没法补。** 打包时必须一起带上。

## 3. 第一轮会发生什么

头里会出现一行（注入的上下文）：

```
[线] 当前：<线头或空> · 下一步：<上次写的 next>
[标签] 当前 T? · 另有 N 条 · 未覆盖 M（含结构事件）
[习惯] 你的习惯：存 · 取 · 认 · …（标题行）
```

然后每轮还会出现：

| 出现 | 含义 | 我该做什么 |
|---|---|---|
| `[归位·上句] 判「…」· 命中 T3` | 引擎自动给上一条消息贴了标 | 不用管（已落） |
| `[候选] T12 · T14 —— 要贴吗？` | 零命中/多命中，需要人判 | 判：贴哪个 / T0 / 新建 |
| `[话题?] 上句更像 T8；凭 …` | 上句像换话题 | 先 `kw-audit explain`，再决定切不切 |
| `[打标?] turn N 还没有标签` | 上一轮漏标 | 立刻 `turnmap.mjs set --turn N --tag Tx` |
| `[死胡同?]`（save 时才出现） | 改动无判据 / 同处改多版 | 先写判据，或换地方改 |

## 4. 四道闸（save 时才会拒绝）

| 闸 | 拒绝条件 | 补法 |
|---|---|---|
| `t0-undecided` | 折叠区间里有未决消息 | `t0decide.mjs decide --seq N --as t0` 或贴标签 |
| `turn-untagged` | 有轮没有标签 | `turnmap.mjs set --turn N --tag Tx` |
| `tags-gap` | 已结束轮里缺 >2 个标签 | `tag-gap.mjs` 看清单补判 |
| `deadend-symptoms` | 同处改多版 / 改完仍同错 / 改动无判据 | 先写判据；真要带债保存，放 `t0-override.json` |

**闸拒绝不是故障**，是“该补的账列出来了”。

## 5. 怎么写 rules.md（重点）

### 5.1 先分清三类规则

| 类 | 例子 | 写不写 |
|---|---|---|
| **不变量** | “未决 = 0”“每轮一个标” | 代码已强制 → **别重复写**，最多写一行指向闸 |
| **操作** | “save 前先跑 newtopics” | **写触发条件**：“当 X 时，跑 Y” |
| **判断** | “迹象 ≠ 状态”“只有用户陈述的结论标待验证” | **写判据**：“如果 A，则 B；反例是 C” |

### 5.2 一条规则的标准形状

```
动词开头 + 触发条件 + 可执行动作（或可判定的判据） +（可选）一条反例
```

好：

> **收到 `[话题?]` 先体检再切**：跑 `kw-audit explain "<上句>"`；带 `(泛)` 的词不算证据 → 不切。

坏：

> 要谨慎对待话题切换，保持敏感。 ← 没有触发条件，没有动作，无法判对错

### 5.3 只从事故里长

**每条规则必须能回答：不加它，会出什么事？**

写法：`事故（一句话） → 规则（一句话）`。事故可以是：
- 一次真实的错误（“我把「跑团」判成泛词”）；
- 一次被用户指正；
- 一次闸拒绝。

**没有事故的规则不写**——那是许愿，不是规则。

### 5.4 上限与合并

- 单个主题 ≤ 40 行；全文 ≤ 12KB；
- 追加前查重（`skill-append.mjs` 或人眼）；
- 同一症状出现两次 → **合并成一条原则**，例证缩成一行；
- 合并后条数必须下降，否则不算合并。

### 5.5 不要写的四类

1. **格言体**：“保持诚实”“不猜不赌”——除非能落成动作；
2. **重复闸**：闸已经挡了的事再写一遍，规则会变长却没变强；
3. **形容词指令**：“尽量”“适当”“灵活”——没有判据；
4. **别人的规则**：从别处抄来的、自己没付过代价的。

### 5.6 演进节奏

```
第 1 天：只有 CONDUCT（30 行）
第 1 周：每次闸拒绝 / 被指正 → 加一条，带事故
第 1 月：合并一次，砍掉重复与格言
```

**参差不齐是对的**：不同鱼有不同的历史，规则自然会不同。**相同的是底层不变量（代码强制）与工具接口**；不同的是判断口味。**不要为了整齐去统一口味**——那会变成表演。

## 6. 常用命令速查

```bash
# 打标
node ~/.dsh/continuity/turnmap.mjs set --turn 1043 --tag T4

# 查表
node ~/.dsh/continuity/match-tags.mjs "这句话像哪个话题"

# 体检一个候选（泛词不算证据）
node ~/.dsh/continuity/kw-audit.mjs explain "上句原文"

# 轮 → seq（给 load 用）
node ~/.dsh/continuity/turnmap.mjs ranges --tag T4

# 判 T0
node ~/.dsh/continuity/t0decide.mjs decide --seq 12345 --as t0

# 标签缺口
node ~/.dsh/continuity/tag-gap.mjs

# 修 session 格式
node ~/.dsh/continuity/doctor.mjs "<session.v4.jsonl.zstd>"
```

## 7. 已知限制（别踩）

1. **C7 只数 `edit/write`**：用 pwsh 脚本改文件，检测器看不到——要么用 edit/write，要么自己数改了几版；
2. **已折叠的混段不切**：切它要重写摘要，等于改历史；它们带 `mixedTags` 标注，取时用窄范围；
3. **load 只能取已入段的区间**：未保存的对话取不到（它本来就在上下文里）；
4. **mood A/B 目前空结果**：五个行为特征全不显著（nA=32 但只有 2 次独立注入，统计单位存疑），**没有证据**支持“痕迹改变风格”；
5. **`tags.json` 会被插件归一化**：自定义字段（如 anchors）会被丢掉，必须放独立文件。

## 8. 出问题时

| 现象 | 先查 |
|---|---|
| save 一直被拒 | 看拒绝码，按码补账（见第 4 节） |
| 头里没有 `[打标?]` 但确实漏标 | `node turnmap.mjs todo` |
| 面板数字不动 | `curl` 本机 `/dsh-continuity/tags.json`（需登录态）或看 `threads.json` mtime |
| session 打不开 | `doctor.mjs` 先诊断，别直接删 |
| 标签判错 | `kw-audit explain` + `match-tags` 双查，别凭感觉改词表 |

---

## 9. 一句话总结

**代码管不变量，规则管判断，事故管规则。**
不变量少而硬，判断多而软，事故是唯一的老师。
