# dsh-continuity 使用说明书（0.4.37）

> **Historical (0.4.37).** 当前版本请读 `README.md` 和 `docs/ARCHITECTURE.md`；下面的路径/行为可能已过时。

> 给新接手的 AI 实例。读完这一份，你应该知道：它是什么、数据在哪、什么自动、什么要你判断、坏了怎么查。

## 1. 它是什么

Continuity 是 DSH 的一个**读侧插件**：它不接管对话，只在每轮请求前**注入一段上下文**，并在你调用 `save` / `load` / `tag` 时维护线头与标签。

三个概念：

- **线头（thread）**：一段工作的存档单元，有 `label`、`next`、`segments`；
- **标签（tag）**：一种归属；一个 seq 可以属于多个标签（多标签）；
- **组（group）**：若干标签的父视图（例如 `设备选购 = [T16, T17]`）。

**能力边界**：它只读会话、写自己的数据目录；**不改宿主程序**。

## 2. 装在哪、版本怎么算

- 插件目录：`coopanion-continuity/dsh-plugin`；
- 安装方式：`~/.dsh/profiles/desktop/node_modules/dsh-continuity` 是指向它的 **junction/link**（不是拷贝）；
- **版本是启动时快照的**：改代码后必须重启才生效。判断方法：比较进程 `StartTime` 与 `package.json` 的 mtime。

## 3. 数据文件（都在 `~/.dsh/continuity/`）

| 文件 | 作用 | 能否手改 |
| --- | --- | --- |
| `threads.json` | 线头、段、gist | 别手改，用工具 |
| `tags.json` | `tags` / `runs` / `overrides` / `memberships` | 别手改，用脚本 |
| `groups.json` | 父视图（`source: manual` / `auto`） | 可手改 |
| `group-evidence.jsonl` | 每次多命中的证据（pair / members / 原句） | 只追加 |
| `groups-answered.json` | 已问/已答的归拢提议 | 只追加 |
| `learning/answered.jsonl` | 学习候选的答复（skip / kept） | 只追加 |
| `learning/candidates.json` | 最近一次扫描的重复错误 | 可删（会重建） |
| `context-log.jsonl` | 每次测量的 estTokens 等 | 只追加 |
| `newtag-asked.json` | 已问过的新标签片段 | 可删 |
| `rules.md` | 我自己的规则（全文只在首轮/折叠后注入） | **该我写** |
| `skills/*.md` | 技能（按线头+关键词注入） | **该我写** |

## 4. 每轮注入链（顺序固定）

1. `[线]` 当前线头 + `next`；
2. `[标签]` 当前标签 + 未覆盖数（**含结构事件**，不是内容遗忘率）；
3. `[习惯]` 规则标题行（全文仅在首轮或承载消息被折叠后重注）；
4. `[技能]` 正在用的技能名 + 一次 `[技能正文]`；
5. `[归位·上句]` 对**上一条**用户消息的判定（唯一 / 多标签 / 零命中）；
6. `[候选]` / `[新标签?]`（只在零命中时）；
7. `[学习]`（重复错误 ≥2 次）；
8. `[归拢]`（多命中证据 ≥2）；
9. `[拆分]`（每 24 轮检查，段数 ≥8）。

**状态没变且上一条头还在 → 不重复注入**（同一签名复用）。

## 5. 什么自动、什么要你判断

完整清单在 `AUTOMATION.md`。摘要：

**自动**：头三行、规则/技能注入、归位（唯一命中写 run、多命中写 memberships、候选唯一自动贴）、学习扫描、归拢证据与强凭据自动建组、拆分提醒、estTokens 落盘。

**你判断**：`[新标签?]` 建不建、`[学习]` skip/kept、`[拆分]` 拆不拆、`load` 取多深、弱凭据归拢（≥2 但 <3）。

**只有人**：训练模式开关、规则长期内容、重启/发布、删除合并标签。

## 6. 工具语义

- `save`：收起当前段，可带 `label`（绑定已有线头）与 `next`（下一轮第一步）；
- `load`：取回某段；默认 6 条有内容的记录，`full:true` 取整段；**切换线头前自动 save 当前线**；
- `tag` / `tag-turn`：落标；可多标签；
- `find`：按“属于”判定（主标签或显式 memberships 都算）；
- `scan`：只看可见区间。

## 7. 重启后自检（四条）

1. 头在、`next` 是最新的；
2. 活跃线头恰好一条；
3. 标签数合理（薄）；
4. `estTokens` 有口径：跑 `node ~/.dsh/continuity/esttokens-check.mjs`，应为 `ok:true`。

附加：内容覆盖率跑 `content-coverage.mjs`，**>2% 才补课**（头里那个数含结构事件，天然偏高，只看趋势）。

## 8. 坏了怎么查

| 症状 | 先查 |
| --- | --- |
| 头没出现 | 插件是否加载、`rules.md` 是否可读、进程是否在跑 |
| 技能正文不注入 | 技能文件是否带 YAML frontmatter（会被剥掉）、BOM 是否存在 |
| 改代码没反应 | **版本自报**：进程启动时间是否晚于 `package.json` |
| 文案里出现 `#` 前多一个怪字符 | 文件被写入了 BOM，需以 UTF-8 无 BOM 重写 |
| 未覆盖数突然涨 | 跑 `uncovered-scan.mjs` 找洞；`backfill-holes.mjs --apply` 可自动插值 |
| 归拢不建组 | 看 `group-evidence.jsonl` 是否满 3 条；父名是否提炼得出 |
