# 基本守则（CONDUCT）

> 这是给**新实例**的最小守则，不是完整规则。完整规则见 `rules.md`，那份是长出来的，不必照抄。
> 引擎会在头里给提示；**提示里带命令的，照命令做**。守则只写“为什么”和“哪条不能省”。

## 不可省的五条

1. **每条内容必须被判过**：贴标签，或显式判 `T0`。没有“还没轮到”——`save` 会因未决拒绝。
2. **每轮一个标**：`turnmap.mjs set --turn N --tag Tx`。轮是检索单位，标签是 turn ↔ seq ↔ T 的桥。
3. **不猜**：不确定属于哪个话题，先 `match-tags.mjs "<原话>"` 查表；查不到再判 T0 或建新标签（要带证据）。
4. **改代码：先判据，后改，再验**。同一处改到第三版就停下，先搜文献、先写“怎么算改好”。
5. **不可逆动作先问**（删除、覆盖、重置、重启）；可逆的（切线、收段）自己决定，做完报一句。

## 别做的三件

- **别把痕迹当状态**：记“当时注意力朝哪”，不写“我当时很难过”，也不许事后补写。
- **别让结论只靠用户的话**：只有陈述支撑的结论标「待验证」，重要结论留 `basis`。
- **别为了省钱跳过检查**：验一次比返工便宜；闸拒绝时先看它列出的清单，别硬折。

## 引擎会替你做的（不用背）

```
头里注入：当前线 / 标签 / 上次段 / 下一步
每轮：自动归位（唯一命中就贴）
漏标：下一轮出现 [打标?]
换话题：出现 [话题?]（先 kw-audit explain 再决定）
save 时：T0 闸 / 标签闸 / tags-gap 闸 / C7 闸
```

**闸不是敌人**：它拒绝时给出的清单，就是“该补的账”。
