# 机制契约（MECHANISM CONTRACT）

> **Historical (0.4.67).** 当前实现与路径请读 `docs/ARCHITECTURE.md`；本契约保留为设计史。

> 这份文件不是实现说明，是**可自检的契约**。
> 任何移植版（包括 Coo 的重写版）只要满足这里的条款，就算“同一个机制”；
> 不满足的条款，必须显式标注为“未实现”，不许假装满足。
>
> 版本对应 dsh-continuity 0.4.67。写于 2026-10-29。

---

## 0. 边界：这套机制是什么、不是什么

**是**：
- 一套“把对话按话题归属 + 把长历史收成可检索段”的机制；
- 一组**不变量**，用闸（gate）在 save 时强制；
- 一组**只读查询**（轮→seq→标签），让实例能自己取回历史。

**不是**：
- 不是上下文压缩算法本身（它调用宿主的 compaction）；
- 不是模型行为约束（它只能拒绝 save，不能阻止模型说话）；
- 不是多租户系统（数据按用户全局，不按会话隔离——见 §7 风险）。

## 1. 数据契约

### 1.1 `tags.json` —— 标签表（唯一的标签来源）

```jsonc
{
  "version": 1,
  "tags": {
    "t-v2-t4": { "label": "Continuity 实现", "alias": "T4", "keywords": ["Continuity", "标签闸"] }
  },
  "runs": [[37567, 38018, "t-v2-t4"]],      // [fromSeq, toSeq, tagId]，追加式，后者覆盖前者
  "overrides": { "12345": "t-v2-t4" },      // seq → tagId，优先级最高
  "memberships": { "12345": ["t-v2-t4"] }   // seq → [tagId]，附加式多标签
}
```

**条款**
- T1.1.1 `T0` **不是**条目，是“未分类”桶；任何代码不得把 `T0` 写进 `tags`、`runs`、`memberships`。
- T1.1.2 `keywords` 是**唯一主源**；其他文件（如 threads）里的关键词只能作回退，冲突时以本文件为准。
- T1.1.3 本文件由插件写入时会**按固定字段归一化**：未知字段会被丢弃。任何扩展字段必须放独立文件。
- T1.1.4 解析某 seq 的标签顺序：`overrides` → 覆盖它的最后一条 `runs` → 附加 `memberships` → 兜底 `T0`。

### 1.2 `threads.json` —— 线头与段（存档索引）

```jsonc
{
  "sessions": {
    "<sessionId>": {
      "activeId": "t-v2-t4",
      "threads": [{
        "id": "t-v2-t4", "alias": "T4", "label": "Continuity 实现",
        "segments": [{
          "fromSeq": 37567, "toSeq": 38018,
          "seqs": [37567, 37568],      // 该段包含的消息 seq（可少于区间，不等于“漏”）
          "count": 130, "tokens": 42788,
          "why": "为什么收起", "next": "下一步",
          "at": "ISO 时间", "spanStart": null, "spanEnd": null, "minutes": 0,
          "archiveRef": null,
          "gistSeq": 38019,            // 仅折叠过的段有
          "compactionId": "..."        // 仅折叠过的段有
        }]
      }]
    }
  }
}
```

**条款**
- T1.2.1 `activeId` **恰好一条**；切换线必须改它。
- T1.2.2 段的 `seqs` 是“指针”，**不是原文**；原文永远只在 session 日志里。
- T1.2.3 段可以重叠、可以乱序插入，但**并集必须覆盖所有消息 seq**（覆盖率 100%，见 §4 不变量 I5）。
- T1.2.4 已折叠段（有 `gistSeq`/`compactionId`）**不得切开**：会把“摘要 ↔ 段”的对应切断。
- T1.2.5 段的 `why`/`next` 是给人读的，不是判据；可为空字符串。

### 1.3 `turn-tags.jsonl` —— 轮标签（轮是检索单位）

```jsonc
{"turn": 1063, "tag": "t-v2-t4", "by": "self|auto|seed|review", "why": "可选", "at": "ISO 时间"}
```

**条款**
- T1.3.1 追加式，**后写覆盖前写**；一行一个轮。
- T1.3.2 `by` 区分来源：`self`（实例判）/ `auto`（引擎推）/ `seed`（历史播种）/ `review`（复核）。
- T1.3.3 每条有消息的轮都必须有一行；没有消息的轮号不算缺。
- T1.3.4 轮号来自 `assistant/message` 或 `turn/start` 的 `data.turn`。**`user/message` 没有 `data.turn`**，不得用它推轮号。

### 1.4 辅助文件（可选，但移植时必须知道它们存在）

| 文件 | 作用 | 缺了会怎样 |
|---|---|---|
| `topic-anchors.json` | 每个标签的“必需词” | 话题提示会按关键词乱切 |
| `generic-words.json` | 泛词表（区分度低） | 泛词会被当成证据 |
| `t0-decisions.jsonl` | 显式判 T0 的记录 | T0 闸无法复核 |
| `groups.json` | 归拢用的组（**不参与搜索**） | 面板少一栏 |
| `backup-state.json` | 冷备状态 | 备份重复或不做 |

## 2. 不变量（INVARIANTS）

移植版必须逐条自检，并在面板/日志里能看到“当前是否满足”。

| # | 不变量 | 判据（可执行） |
|---|---|---|
| **I1** | 每条有内容的消息都有归属 | 对全量消息跑 `tagsAtSeq`；结果不得为 `null`（兜底 `T0` 也算有归属，但 `T0` 比例要可解释） |
| **I2** | 每条有消息的轮都有轮标签 | `turn-tags` 的轮集合 ⊇ 有消息的轮集合 |
| **I3** | 每条内容都被“判过” | 未决消息数 = 0（未决 = 有内容、无标签、无显式 T0 决定） |
| **I4** | 折叠后原文可取回 | 任一已折叠段，都能用 `load fromSeq..toSeq` 取回原消息 |
| **I5** | 段覆盖率为 100% | 所有消息 seq ∈ 某个段的区间；`uncovered = 0` |
| **I6** | 关键词只有一个主源 | 改 `tags.json` 的关键词，匹配行为必须跟着变 |
| **I7** | 活跃线恰好一条 | `threads.json.activeId` 存在且指向存在的 thread |

**自检脚本建议**（移植版自己实现，或照抄本仓库同名脚本）：
```
I1/I5 → coverage.mjs（消息全量 vs 段区间）
I2    → turnmap.mjs todo
I3    → t0-gate.mjs
I4    → 任取一个 gistSeq 段，load 一次比对条数
I6    → 改一个词的匹配行为，再改回去
I7    → 读 threads.json 的 activeId
```

## 3. 闸（GATES）——save 时才拒绝

**闸的作用是“把该补的账列出来”，不是惩罚。**

| 闸 | 触发条件 | 拒绝码 | 补法 |
|---|---|---|---|
| T0 闸 | 折叠区间内有“未决消息” | `t0-undecided` | `t0decide.mjs decide --seq N --as t0`，或贴标签 |
| 轮标签闸 | 折叠区间内有轮没有标签 | `turn-untagged` | `turnmap.mjs set --turn N --tag Tx` |
| 缺口闸 | 已结束的轮里缺 >2 个标签 | `tags-gap` | `tag-gap.mjs` 列清单 → 补判 |
| 死胡同闸 | 折叠区间尾部 12 轮出现：同处改多版 / 改完仍同错 / 改动无判据 | `deadend-symptoms` | 先写判据；真要带债保存，放 `t0-override.json` |

**条款**
- T3.1 闸只能**拒绝**，不能修改数据。
- T3.2 每个拒绝码必须带**可执行的补法命令**；否则这条闸就是“拒绝但没法修”。
- T3.3 `t0-override.json` 是一次性放行（读完即删），用于“我知道有债，先存”。
- T3.4 闸自身的异常**不得阻断 save**（宁可漏闸，不可卡死）。

## 4. 工具契约

所有工具是**本地脚本**，不联网。移植版必须提供等价命令（名字可不同，语义必须同）。

| 命令 | 输入 | 输出 | 失败码 |
|---|---|---|---|
| `turnmap set` | `--turn N --tag Tx [--by self]` | 一行确认 | 参数缺失 → 退出 2 |
| `turnmap todo` | 无 | `{totalTurns, todo, sample}` | 读不到会话 → 退出 1 |
| `turnmap ranges` | `--tag Tx` | `{tag, turns, ranges[]}` | 未知标签 → 空列表 |
| `turnmap show` | `--turn N` | `{turn, seq, tag, by}` | — |
| `t0decide decide` | `--seq N --as t0\|tag:Tx --reason R` | 追加一行决定 | — |
| `t0decide status` | `--from S` | 未决清单 | — |
| `tag-gap` | 无 | 缺口清单 | — |
| `newtopics` | `--from S --review` | 每轮首句 + `best` | — |
| `match-tags` | `"<文本>"` | 候选（含 score/hit） | 空 = 无候选 |
| `kw-audit explain` | `"<文本>"` | 命中词 + 是否泛词 + verdict | 无泛词表 → 视为全部不泛 |
| `doctor` | `<session 文件>` | violations + verdict | 解析失败 → 退出 1 |

**条款**
- T4.1 所有工具**只读或追加**，除 `turnmap set` / `t0decide` / `doctor --fix` 外不得改文件。
- T4.2 `doctor --fix` 必须写到新文件，**绝不覆盖原文件**。
- T4.3 输出必须是 JSON 或可 grep 的行；不要“看起来像成功”的散文。

## 5. 注入契约（体现为“头”）

每轮开始，宿主侧应提供（顺序不重要，内容重要）：

```
[线] 当前：<线头> · 下一步：<next>
[标签] 当前 T<x> · 另有 N 条 · 未覆盖 M（含结构事件）
[习惯] 标题行（不是全文）
[归位·上句] 判「…」· 命中 T3 → 已自动归入
[打标?] 缺 N 轮（…）        ← 只在缺口存在时
[话题?] 上句更像 T8；凭 …    ← 只在候选≠当前线时
[死胡同?] …                  ← 只在 save 闸预检命中时
```

**条款**
- T5.1 注入**只追加到对话尾部**，不得写进 system/tool 前缀。
- T5.2 每条提示都必须**自解释**（含“我该跑什么命令”）。
- T5.3 注入失败**不得阻断回合**；但必须在日志里留下 `inject-*` 记录，可用于审计。

## 6. 已知的静默失败点（移植时最容易丢）

按踩坑顺序，每一条都真实发生过：

| # | 塌陷方式 | 症状 | 防御 |
|---|---|---|---|
| 1 | 关键词双源（threads 覆盖 tags） | 改词无效，**不报错** | I6 + 启动时打印“关键词源” |
| 2 | `tags.json` 归一化吃自定义字段 | anchors 消失，**不报错** | 扩展字段放独立文件；启动时校验文件存在 |
| 3 | 重切段时漏掉“无标签 seq” | 覆盖率 99.68%，**不报错** | 每次重切后强制跑 I5 |
| 4 | 备份文件名重复前缀 | 清理不生效，**不报错** | 备份后打印实际文件名与保留份数 |
| 5 | 轮标签只有“上一轮”提醒 | 早期漏标永久沉底 | 提醒必须报**整段缺口**（见 [打标?] 格式） |
| 6 | 闸只给拒绝码不给补法 | 实例卡死 | T3.2 |
| 7 | `load` 被当成“会清空上下文” | 用它去断循环，无效 | 明确：load 只追加 |

**判断标准**：任何一个防御点，**如果它失效了，屏幕上必须有东西变红/变吵**。静默 = 没实现。

## 7. 多实例风险（如果 Coo 与我在同一台机器）

- `tags.json` / `threads.json` / `turn-tags.jsonl` 是**按用户全局**，不是按会话隔离。
- 两个实例同时写，会互相覆盖轮号与标签 → **数据打架**。
- 因此交接的第一阶段只能**只读**：读 tags.md / 面板 / threads 索引，不写。
- 要真正共写，需要先加“每会话命名空间”（当前未实现）。

## 8. 移植验收清单（照着打勾）

```
[ ] 1. 三个数据文件存在且能解析（tags / threads / turn-tags）
[ ] 2. I1–I7 全部跑一遍，结果贴进日志
[ ] 3. 制造一次“漏标”，下一轮必须出现 [打标?] 且带完整缺口
[ ] 4. 制造一次“未决”，save 必须被拒，补完后必须放行
[ ] 5. 任取一个已折叠段，load 回来比对条数一致（I4）
[ ] 6. 改一个关键词，匹配行为必须变（I6），改回必须复原
[ ] 7. 备份跑一次：文件名正确、保留份数正确
[ ] 8. 故意写一个非法标签（T0 进 runs），自检必须报出来
```

**八条全过 = 机制移植成功；任何一条不过，都还算“看起来像”。**

## 9. 一句话

> **机制不是代码，是“不变量 + 闸 + 可查的数据”。**
> 代码可以重写，不变量不能重写。
