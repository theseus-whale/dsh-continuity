# Guides

Current quickstart:

1. Read [README](../README.md) and [INSTALL](../INSTALL.md).
2. Keep public defaults off.
3. Create the local overlay explicitly.
4. Run `dsh-continuity migrate audit` and `migrate plan` before any apply.
5. Open [PANEL](../PANEL.md) to read current Host state.

Historical guides are under `guides/archive/`; they are not install steps.
